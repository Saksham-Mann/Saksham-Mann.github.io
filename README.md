# Saksham-Mann.github.io

Welcome to my frontend design repository! This repository hosts a collection of high-quality frontend projects. 

## UI/UX Design

The landing page of this repository is built with a modern, spatial UI design approach. It features:
- **Glassmorphism**: A frosted-glass effect for the main container that adds depth and a premium feel.
- **Micro-animations**: Smooth, subtle animations for entry, hover states, and interactions.
- **Dynamic Aesthetics**: A responsive, visually engaging layout that prioritizes a seamless user experience.
- **Custom 404 Void Experience**: A meticulously designed 404 error page featuring a responsive split-layout and a background gradient mask that simulates "falling into the void" to maintain the immersive spatial UI theme even on missing paths.
